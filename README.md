# Appointment Booking System

A web app for booking appointments online, replacing manual scheduling with a clean digital flow.

**Live demo:** https://appointment-system-sepia.vercel.app

## Tech Stack

- React 19 + TypeScript + Vite
- Redux Toolkit for state management
- TanStack React Query + Axios for data fetching
- React Hook Form with schema validation
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`, `npm run preview`.
